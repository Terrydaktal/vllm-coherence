# Coherence benchmarks

The [shared benchmark suite](../docs/BENCHMARK_SUITE.md) documents the current
runners in `experiments/radiance-public/`, their required fixtures, and the
isolated GPU procedure. See the [main README](../README.md#benchmarks) and
[results](results/) for published measurements. Keep raw captures in the ignored
`benchmarks/runs/` directory or the private benchmark lab.

Earlier Coherence result files and the inherited Radiance benchmark harness
are available at the [archived revision](https://github.com/Terrydaktal/vllm-coherence/tree/3cbf9c17e8cef4736563c8ddab514b6874fd96ad/benchmarks).
The [original Radiance result archive](https://github.com/Terrydaktal/vllm-coherence/tree/4e604dcccb311ca709858a4bd57a11fc636e7f43/benchmarks/results)
contains the 28 inherited result directories.
